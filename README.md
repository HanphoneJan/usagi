# 🐰 Usagi Desktop Pet

### ✨ 特性

- 🎭 **13种动画状态**：站立、行走、跳跃、爬行、扭动、倾斜、攀爬、天花板移动等
- 🌍 **物理引擎**：重力、碰撞检测、弹跳阻尼、空气摩擦
- 🎮 **丰富交互**：点击、拖拽、双指捏合触发不同动作
- 🔊 **32种音效**：根据动作播放对应的可爱音效
- ⚙️ **个性化设置**：音量、动画速度、开机自启、显示/隐藏
- 📱 **多位置支持**：地面、墙壁、天花板自由移动


### 🎯 使用指南

| 操作         | 效果                             |
| ------------ | -------------------------------- |
| 点击         | 触发随机动作（跳跃、扭动、倾斜） |
| 长按拖拽     | 移动角色位置                     |
| 双指捏合     | 触发夹取动作，可攀爬至天花板     |
| 拖到屏幕上方 | 触发攀爬到天花板                 |
| 拖到屏幕下方 | 返回地面                         |

### 📁 项目结构

```
usagi/
├── app/src/main/java/com/example/usagi/
│   ├── MainActivity.java       # 主界面
│   ├── UsagiService.java       # 悬浮窗服务
│   ├── UsagiView.java          # 核心渲染与交互
│   ├── SettingsActivity.java   # 设置界面
│   └── BootReceiver.java       # 开机自启
├── app/src/main/res/
│   ├── drawable/               # 27张动画帧
│   └── raw/                    # 32个音效文件
└── build.gradle
```

### 🔧 技术栈

- **语言**: Java
- **架构**: Service + 自定义 View
- **动画**: 帧动画 + 物理引擎
- **音频**: SoundPool
- **悬浮窗**: WindowManager
