# 乌萨奇桌宠安卓端

## 项目简介
这是一个基于Android平台的桌宠应用，使用提供的图片和音频素材，实现了一个可以在安卓设备桌面上自由移动、交互的乌萨奇角色。

## 开发环境
- **操作系统**：Windows 11
- **开发工具**：Android Studio 4.2+ 
- **SDK版本**：
  - 最低SDK版本：24 (Android 7.0)
  - 目标SDK版本：33 (Android 13.0)
- **构建工具**：Gradle 8.0.0

## 如何导入和运行项目

### 1. 在Android Studio中导入项目
1. 打开Android Studio
2. 选择「File」->「Open」
3. 导航到项目目录 `e:\develop_project\usagi`
4. 点击「OK」按钮导入项目
5. Android Studio会自动下载所需依赖并构建项目

### 2. 运行项目
1. 确保已连接Android设备或启动了模拟器
2. 点击工具栏中的「Run」按钮或使用快捷键 `Shift+F10`
3. 在弹出的「Select Deployment Target」窗口中选择设备
4. 点击「OK」按钮开始安装和运行应用

## 如何构建和打包APK

### 1. 构建Debug版本
1. 在Android Studio中，选择「Build」->「Build Bundle(s) / APK(s)」->「Build APK(s)」
2. 构建完成后，会在右下角显示「APK(s) generated successfully」
3. 点击「locate」按钮可以找到生成的APK文件，通常位于 `app\build\outputs\apk\debug\` 目录

### 2. 构建Release版本
1. 配置签名密钥：
   - 选择「Build」->「Generate Signed Bundle / APK...」
   - 选择「APK」并点击「Next」
   - 点击「Create new...」创建新的密钥库
   - 填写密钥库信息，包括密钥库路径、密码、密钥别名和密钥密码
   - 点击「OK」保存密钥库配置
2. 选择构建类型：
   - 选择「Release」构建类型
   - 点击「Finish」开始构建
3. 构建完成后，APK文件将生成在 `app\build\outputs\apk\release\` 目录

## 功能说明

### 1. 核心功能
- **桌宠显示**：在设备桌面上显示乌萨奇角色
- **物理引擎**：实现符合物理逻辑的动作切换和移动系统
- **动画系统**：支持13种动画状态：
  - **下落 (FALL)**：角色从屏幕上方落下，带有重力效果
  - **站立 (STAND)**：角色静止站立
  - **行走 (WALK)**：角色水平移动
  - **弹跳 (BOUNCE)**：落地时的弹跳效果
  - **坐下 (SIT)**：角色坐下休息
  - **倾斜 (TIP)**：角色身体倾斜
  - **扭动 (TWIST)**：角色左右扭动
  - **跳跃 (JUMP)**：角色向上跳跃
  - **爬行 (CREEP)**：角色在地面爬行
  - **左夹取 (PINCH_LEFT)**：向左做出夹取动作
  - **右夹取 (PINCH_RIGHT)**：向右做出夹取动作
  - **攀爬 (CLIMB)**：从地面攀爬到天花板
  - **天花板 (CEIL)**：角色在天花板上活动

- **位置状态系统**：
  - **地面 (FLOOR)**：角色在屏幕底部
  - **空中 (AIR)**：角色在移动或下落中
  - **天花板 (CEILING)**：角色在屏幕顶部

- **交互功能**：
  - **点击**：短按角色触发随机动作
  - **拖拽**：长按并拖动角色到目标位置
    - 拖到屏幕上方1/3：触发攀爬到天花板
    - 拖到屏幕下方1/3：回到地面
    - 拖到中间区域：保持当前状态
  - **双指捏合**：触发夹取动作（PINCH_LEFT/PINCH_RIGHT）
  - **自动动作**：无交互时，每隔3-8秒随机触发一个动作

### 2. 物理逻辑
- **出场动画**：角色从屏幕上方FALL到屏幕边缘
- **位置转换**：
  - 地面 → 天花板：必须执行PINCH_LEFT或PINCH_RIGHT动作后才能攀爬（CLIMB）到天花板
  - 天花板 → 地面：点击或双指捏合可使角色跳下
- **重力系统**：角色下落时带有重力加速度
- **碰撞检测**：角色在碰到屏幕边界时会反弹或停止
- **音量调节**：调整音效音量
- **动画速度**：调整角色动画播放速度
### 3. 设置功能
- **音量调节**：调整音效音量
- **动画速度**：调整角色动画播放速度
- **开机自启**：设置是否在设备开机时自动启动桌宠
- **显示/隐藏**：控制桌宠的显示和隐藏

## 使用说明

### 1. 首次使用
1. 安装并打开应用
2. 点击「启动桌宠」按钮
3. 如果是首次使用，会弹出悬浮窗权限申请界面
4. 点击「允许」授予悬浮窗权限
5. 桌宠将在桌面上显示并开始运行

### 2. 基本操作
- **启动桌宠**：点击主界面的「启动桌宠」按钮
- **停止桌宠**：点击主界面的「停止桌宠」按钮
- **打开设置**：点击主界面的「设置」按钮
- **点击交互**：短按角色触发随机动作（跳跃、弹跳、倾斜、扭动）
- **拖拽移动**：长按角色并拖动到目标位置
  - 拖到屏幕上方1/3区域：角色会攀爬到天花板
  - 拖到屏幕下方1/3区域：角色会回到地面
- **双指捏合**：两个手指同时触摸角色触发夹取动作
  - 地面状态下：触发PINCH_LEFT或PINCH_RIGHT，然后攀爬到天花板
  - 天花板状态下：使角色跳回地面

### 3. 设置说明
- **音量**：拖动滑块调整音效音量大小
- **动画速度**：拖动滑块调整动画播放速度
- **开机自启**：开启后，设备开机时会自动启动桌宠
- **显示桌宠**：关闭后，桌宠将隐藏但仍在后台运行

## 注意事项

1. **悬浮窗权限**：应用需要悬浮窗权限才能在桌面上显示桌宠，请确保已授予该权限
2. **后台运行**：桌宠以前台服务形式运行，可能会消耗一定的电量和内存
3. **兼容性**：支持Android 7.0及以上版本的设备
4. **性能优化**：如果设备性能较低，可能会出现动画卡顿现象，可以尝试降低动画速度

## 故障排除

### 1. 桌宠无法显示
- 检查是否已授予悬浮窗权限
- 检查设置中的「显示桌宠」选项是否开启
- 尝试重启应用

### 2. 音效不播放
- 检查设备音量是否开启
- 检查应用设置中的音量是否调整到合适大小

### 3. 应用崩溃
- 确保设备系统版本符合要求
- 尝试清除应用数据并重新启动
- 检查是否有其他应用冲突

## 开发说明

### 主要类说明
- **MainActivity**：应用主界面，处理用户交互
- **UsagiService**：悬浮窗服务，负责管理桌宠的生命周期
- **UsagiView**：桌宠核心视图，处理绘制、动画和交互
- **SettingsActivity**：设置界面，处理用户设置
- **BootReceiver**：开机自启广播接收器

### 资源说明
- **图片资源**：位于 `res/drawable/` 目录
  - 包含27张动画帧图片，支持13种动作
  - 动作类型：fall(下落)、stand(站立)、walk(行走)、bounce(弹跳)、sit(坐下)、
    tip(倾斜)、twist(扭动)、jump(跳跃)、creep(爬行)、pinch_left(左夹取)、
    pinch_right(右夹取)、climb(攀爬)、ceil(天花板)
- **音频资源**：位于 `res/raw/` 目录
  - 包含32个音效文件
  - 音效类型：ha系列、hum系列、puru系列、wula系列、yaha系列等

### 自定义功能
如果需要自定义桌宠的行为或外观，可以修改以下文件：
- `UsagiView.java`：修改动画逻辑、交互行为和移动算法
- `UsagiService.java`：修改悬浮窗配置和服务逻辑
- 替换 `drawable/` 目录中的图片资源可以更换角色外观
- 替换 `raw/` 目录中的音频资源可以更换音效
