# 安卓桌宠应用开发计划

## 项目概述
开发一个名为"乌萨奇"的安卓桌宠应用，使用material文件夹中的图片和音频素材，支持在安卓平板和手机上运行。

## 开发环境
- 操作系统：Windows 11
- 开发工具：Android Studio
- 语言：Java/Kotlin
- 目标API：Android 10.0 (API 29) 及以上

## 项目结构设计
1. 创建标准安卓项目结构
2. 将素材资源导入到项目中：
   - 图片资源放入 `res/drawable/` 目录
   - 音频资源放入 `res/raw/` 目录

## 核心功能设计

### 1. 桌宠显示与动画
- 使用 `ImageView` 或自定义 `View` 显示乌萨奇角色
- 实现帧动画，使用提供的PNG序列图
- 支持多种动画状态：待机、移动、触摸反应等

### 2. 交互功能
- 触摸事件处理：点击、长按、拖动
- 触摸时播放对应音效
- 根据不同触摸行为切换动画状态

### 3. 移动功能
- 实现自动移动算法
- 边界检测，防止角色移出屏幕
- 随机移动路径生成

### 4. 后台运行
- 实现悬浮窗功能，使用 `WindowManager`
- 处理系统权限申请（`SYSTEM_ALERT_WINDOW`）
- 支持应用在后台持续运行

### 5. 设置功能
- 音量调节
- 动画速度调节
- 显示/隐藏开关
- 开机自启选项

## 开发步骤

1. **创建安卓项目**
   - 使用Android Studio创建新的安卓项目
   - 配置项目基本信息（包名、目标API等）

2. **导入资源**
   - 将material文件夹中的图片导入到drawable目录
   - 将音频文件导入到raw目录

3. **实现核心组件**
   - 创建桌宠View类，处理绘制和动画
   - 实现动画管理器，控制不同状态的动画切换
   - 实现音频管理器，处理音效播放

4. **实现交互逻辑**
   - 处理触摸事件
   - 实现角色移动算法
   - 关联触摸行为与动画/音效

5. **实现悬浮窗功能**
   - 申请系统权限
   - 创建Service用于后台运行
   - 配置WindowManager参数

6. **添加设置界面**
   - 创建设置Activity
   - 实现各项设置选项
   - 保存设置到SharedPreferences

7. **测试与优化**
   - 在不同设备上测试兼容性
   - 优化性能，减少内存占用
   - 修复bug

## 技术要点

- 使用 `AnimationDrawable` 实现帧动画
- 使用 `MediaPlayer` 或 `SoundPool` 播放音效
- 使用 `WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY` 实现悬浮窗
- 处理不同屏幕分辨率的适配
- 实现省电模式，减少后台资源消耗

## 预期效果
- 乌萨奇角色在安卓设备桌面上自由移动
- 触摸时产生互动反应和音效
- 支持多种动画状态切换
- 可通过设置调整应用行为
- 稳定在后台运行，不影响设备正常使用
